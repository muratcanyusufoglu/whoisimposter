Quem é o Impostor? é a coleção definitiva de jogos offline para grupos de 3–15 jogadores. Um só celular. Sem WiFi. Diversão sem limites.

 O CLÁSSICO JOGO DO ESPIÃO
Todos os jogadores veem uma palavra secreta — exceto o Impostor, que vê apenas "???". Você consegue se misturar ao grupo sem ser descoberto? Ou o grupo vai expor o spy escondido entre vocês?

COMO JOGAR O IMPOSTOR:
1. Digite os nomes dos jogadores (3–15 jogadores)
2. Passe o celular — cada jogador vê secretamente sua palavra (o Impostor vê "???")
3. Discussão: cada um dá uma dica sobre a palavra secreta
4. Votação: quem está agindo de forma suspeita?
5. Revelação: o grupo pegou o spy — ou o impostor escapou?
